# مواقيت الصلاة — Prayer Times

تطبيق أندرويد بواجهة عربية، يعرض مواقيت الصلاة ويشغّل الأذان بالصوت الذي تختاره، ويذكّرك بإقامة كل صلاة. يعمل بدون إنترنت وبدون إعلانات أو حساب مستخدم.

**[تحميل التطبيق للأندرويد — PrayerTimes 1.1](https://github.com/HamdyRabie/PrayerTimes/releases/download/v1.1/PrayerTimes_1.1.apk)**

[جميع الإصدارات وملفات التحميل](https://github.com/HamdyRabie/PrayerTimes/releases)

## التشغيل

1. حمّل ملف APK من الرابط أعلاه وافتحه لتثبيت التطبيق. يحتاج Android 8 أو أحدث.
2. اختر مدينتك. المدينة الافتراضية: العاشر من رمضان.
3. شغّل «تنبيهات الصلاة»، واسمح بالإشعارات وبالمنبهات والتذكيرات.
4. اضبط عدد دقائق الإقامة لكل صلاة حسب مسجدك. الأرقام المبدئية قابلة للتغيير.
5. اختر صوت المؤذن من «اختيار صوت المؤذن ومعاينته»، ثم اضغط «حفظ».
6. اختبر الأذان والإقامة بعد دقيقة والشاشة مقفولة، وارفع مستوى صوت المنبّه في الهاتف.

يمكن تثبيت الإصدار 1.1 فوق الإصدار 1.0 الموقّع بنفس المفتاح للاحتفاظ بالإعدادات.

## الخصائص

- مواقيت الفجر والشروق والظهر والعصر والمغرب والعشاء.
- أربعة أصوات أذان مدمجة: محمد رفعت، مشاري راشد العفاسي، ناصر القطامي، أحمد النفيس.
- تسجيلات إضافية بجودتها الرقمية الأصلية من 128 إلى نحو 200 kbps، دون إعادة ضغط. تسجيل محمد رفعت التاريخي متاح بجودته الأصلية.
- تذكير مستقل للإقامة بجرس قصير وإشعار، بعد 1 إلى 120 دقيقة من أذان كل صلاة.
- تشغيل أو كتم الأذان والإقامة لكل صلاة بصورة مستقلة.
- اختيار المدينة، وطريقة الحساب، ومذهب العصر، وتعديل دقائق الصلاة.
- تشغيل كامل بدون إنترنت، مع إعادة ضبط التنبيهات بعد تشغيل الهاتف أو تغيير الساعة.

راجع مواقيت الصلاة مع تقويم بلدك واضبط دقائق الإقامة حسب مسجدك. القيم المبدئية للإقامة ليست جدولًا معتمدًا لأي مسجد.

## للمطورين

المشروع Java أصلي للأندرويد، بحد أدنى API 26 وهدف API 36، ويستخدم Adhan Java 1.2.1 لحساب المواقيت.

افتح المجلد في Android Studio، ثم شغّل:

```sh
bash gradlew assembleDebug
```

على Windows استخدم `gradlew.bat assembleDebug`. توجد طريقة بناء بديلة في `tools/build_apk.py`، وتفاصيل التشغيل في [الدليل العربي](README_AR.md).

مفتاح توقيع النسخة المنشورة محفوظ خارج المستودع. البناء المحلي ينشئ حزمة اختبار خاصة بالمطور؛ لتحديث النسخة المنشورة يجب أن يوقّع مالك المشروع الإصدار بمفتاح التوزيع الأصلي.
